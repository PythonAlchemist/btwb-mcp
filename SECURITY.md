# Security Policy

This project handles a BTWB session cookie, which grants full access to whatever BTWB account it belongs to. Treat it like a password: don't commit it, log it, or paste it somewhere public (see the README's Setup and Privacy sections for how it's meant to be stored).

## Reporting a vulnerability

If you find a security issue - e.g. a way the client could leak a cookie, a request that doesn't validate input before sending it, or anything else with security impact - please report it privately via [GitHub's "Report a vulnerability" feature](https://github.com/jchan023/btwb-mcp/security/advisories/new) on this repo, rather than opening a public issue.

This is an unofficial, unsupported side project maintained by one person in their spare time - there's no SLA, but reports will be looked at and fixes released as soon as reasonably possible.
